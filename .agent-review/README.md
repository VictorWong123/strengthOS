# Agent Review Memory

Local Codex review and insight memory lives here.

Use this directory alongside `AGENTS.md` when doing reviews, repeated-mistake analysis, or local-memory-assisted work. Keep reusable folder structure in git, but do not commit generated review payloads, incidents, imported transcripts, or private memory files.

Expected folders:

- `reviews/`: review outputs and classifications.
- `incidents/`: concise incident summaries.
- `summaries/`: conversation or session summaries.
- `insights/pending/`: proposed insights awaiting user approval.
- `insights/approved/`: user-approved reusable lessons.
- `insights/rejected/`: rejected or false-positive insight metadata.
